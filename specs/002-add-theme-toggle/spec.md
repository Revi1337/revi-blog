# Feature Specification: 헤더 테마 토글 버튼 추가

**Feature Branch**: `002-add-theme-toggle`

**Created**: 2026-07-17

**Status**: Draft

**Input**: User description: "헤더 네비게이션에 dark/light 테마 토글 버튼을 추가한다. 지금 정적 HTML에는 이 버튼이 없고 dark/light가 별개의 파일(URL)로만 존재하는데, 이제 같은 화면 안에서 버튼 클릭으로 즉시 테마를 전환할 수 있어야 한다. 토글 버튼의 시각적 디자인(아이콘 모양, 헤더 내 위치, 클릭 시 인터랙션/애니메이션)은 https://me.revi1337.com 헤더에 있는 토글과 동일해야 한다."

## User Scenarios & Testing *(mandatory)*

### User Story 1 — 버튼 클릭으로 테마 전환 (Priority: P1)

블로그 방문자가 헤더의 테마 토글 버튼을 클릭하면, 페이지 리로드 없이 dark ↔ light 테마가 즉시 전환된다. 더 이상 별도의 URL로 이동할 필요가 없다.

**Why this priority**: 이 기능의 핵심 목적이다. 사용자가 같은 화면 안에서 원클릭으로 테마를 전환할 수 있어야 한다.

**Independent Test**: 아무 페이지(홈 또는 아티클 상세)에서 테마 토글 버튼을 클릭한 뒤, 페이지 리로드 없이 배경색·텍스트색·액센트색이 즉시 변경되는지 확인할 수 있다.

**Acceptance Scenarios**:

1. **Given** dark 테마 상태의 페이지를 보고 있을 때, **When** 헤더의 테마 토글 버튼을 클릭하면, **Then** 페이지 리로드 없이 light 테마로 즉시 전환된다 (배경색, 텍스트색, 액센트색, 보더 등 모든 색상이 변경됨)
2. **Given** light 테마 상태의 페이지를 보고 있을 때, **When** 헤더의 테마 토글 버튼을 클릭하면, **Then** 페이지 리로드 없이 dark 테마로 즉시 전환된다
3. **Given** 테마가 전환된 상태에서, **When** 같은 사이트 내 다른 페이지로 이동하면, **Then** 선택한 테마가 유지된다

---

### User Story 2 — 레퍼런스 사이트와 동일한 버튼 디자인 (Priority: P1)

테마 토글 버튼의 시각적 디자인(아이콘, 위치, 크기, 호버 효과)이 https://me.revi1337.com 헤더의 토글 버튼과 동일하다.

**Why this priority**: 사용자 요구사항에서 레퍼런스 사이트와 동일한 디자인을 명시적으로 요구했다. 디자인 일관성은 이 블로그 브랜드의 핵심이다.

**Independent Test**: 재구현된 토글 버튼과 레퍼런스 사이트(me.revi1337.com)의 토글 버튼을 나란히 놓고 시각적으로 비교할 수 있다.

**Acceptance Scenarios**:

1. **Given** 헤더 네비게이션 바를 보면, **When** 토글 버튼의 위치를 확인하면, **Then** 네비게이션 우측 영역에 구분선(|)으로 다른 요소와 분리되어 배치된다
2. **Given** dark 테마 상태에서, **When** 토글 버튼의 아이콘을 확인하면, **Then** 태양(sun/light_mode) 아이콘이 표시된다 (light 모드로 전환할 수 있음을 의미)
3. **Given** light 테마 상태에서, **When** 토글 버튼의 아이콘을 확인하면, **Then** 달(moon/dark_mode) 아이콘이 표시된다 (dark 모드로 전환할 수 있음을 의미)
4. **Given** 토글 버튼 위에 마우스를 올리면, **When** 호버 상태가 되면, **Then** 아이콘 색상이 변경되고 배경에 미세한 하이라이트가 나타나는 등 레퍼런스 사이트와 동일한 호버 효과가 적용된다
5. **Given** 토글 버튼의 크기를 확인하면, **When** 레퍼런스 사이트와 비교하면, **Then** 클릭 가능 영역(32×32px)과 아이콘 크기(18×18px)가 동일하다

### User Story 3 — 테마 선택 기억 (Priority: P2)

블로그 방문자가 테마를 선택한 뒤 브라우저를 닫고 다시 방문하면, 이전에 선택한 테마가 적용된다.

**Why this priority**: 사용자 경험의 연속성을 위해 중요하지만, 핵심 전환 기능(P1)이 먼저 완성되어야 한다.

**Independent Test**: 테마를 전환한 뒤 브라우저를 닫고, 동일한 페이지를 다시 열어 이전 테마가 유지되는지 확인할 수 있다.

**Acceptance Scenarios**:

1. **Given** 사용자가 light 테마로 전환한 상태에서, **When** 브라우저를 닫고 같은 페이지를 다시 방문하면, **Then** light 테마가 유지된다
2. **Given** 사용자가 처음 방문(저장된 선택 없음)할 때, **When** 페이지가 로드되면, **Then** 시스템 기본 설정(OS 테마) 또는 dark 테마가 기본값으로 적용된다

---

### Edge Cases

- 테마 전환 시 진행 중인 CSS 애니메이션(캐러셀 자동 재생 등)이 중단되지 않아야 한다
- 아티클 상세 페이지의 코드 블록, 메트릭 카드, TOC 사이드바 등 모든 요소가 테마 전환에 정확히 반응해야 한다
- dark 테마 전용 효과(터미널 글로우)는 light 전환 시 비활성화되고, dark로 돌아오면 다시 활성화되어야 한다
- 빠르게 연속 클릭(더블·트리플 클릭)해도 최종 상태가 정확해야 한다 (중간 상태에 멈추지 않음)
- 모바일 뷰포트에서도 토글 버튼이 접근 가능하고 터치 가능해야 한다

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 헤더 네비게이션 바의 우측 영역에 테마 토글 버튼을 표시해야 한다 — 구분선(|)으로 인접 요소와 분리되며, 클릭 가능 영역은 32×32px, 아이콘 크기는 18×18px이어야 한다
- **FR-002**: dark 테마 상태에서 버튼 아이콘은 태양(sun/light_mode)을, light 테마 상태에서는 달(moon/dark_mode)을 표시해야 한다
- **FR-003**: 토글 버튼 클릭 시 페이지 리로드 없이 dark ↔ light 테마가 즉시 전환되어야 한다 — 배경색, 텍스트색, 액센트색, 보더 색상 등 모든 색상 토큰이 변경된다
- **FR-004**: 토글 버튼의 호버 효과는 레퍼런스 사이트(me.revi1337.com)와 동일해야 한다 — 아이콘 색상 변경과 배경 하이라이트
- **FR-005**: 사용자가 선택한 테마는 브라우저 세션 간에 유지되어야 한다 (재방문 시 이전 선택 적용)
- **FR-006**: 사용자의 저장된 테마 선택이 없을 경우, 운영체제의 시스템 테마 설정을 따르되 이것도 없으면 dark 테마를 기본값으로 적용해야 한다
- **FR-007**: 테마 전환 시 홈 화면과 아티클 상세 화면의 모든 UI 요소(네비게이션 바, 캐러셀, 카드, 코드 블록, TOC, 메트릭 카드, 푸터 등)가 정확하게 색상을 변경해야 한다
- **FR-008**: 같은 사이트 내 페이지 간 이동 시 현재 선택된 테마가 유지되어야 한다
- **FR-009**: 토글 버튼은 접근성을 위한 적절한 레이블을 가져야 한다 — dark 상태에서 "라이트 모드로 전환", light 상태에서 "다크 모드로 전환" 등
- **FR-010**: 토글 버튼은 홈 화면과 아티클 상세 화면 모두에서 동일한 위치·크기·동작으로 표시되어야 한다 (공유 UI 요소로 관리)

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사용자가 테마 토글 버튼을 1회 클릭하면 0.3초 이내에 전체 화면의 색상이 전환된다 (체감 즉시)
- **SC-002**: 토글 버튼의 시각적 디자인(아이콘, 크기, 위치, 호버 효과)이 레퍼런스 사이트(me.revi1337.com)와 육안 비교 시 동일하다
- **SC-003**: 테마를 선택한 뒤 브라우저를 닫고 재방문했을 때 100% 이전 선택이 유지된다
- **SC-004**: 테마 전환 후 화면의 모든 UI 요소가 해당 테마의 색상 팔레트를 정확히 반영한다 (누락된 요소 0개)
- **SC-005**: 토글 버튼 클릭 시 페이지 리로드가 발생하지 않는다 (네트워크 요청 0건)

## Assumptions

- 이 기능은 001-component-blog-rewrite 기능이 완성된 이후에 구현된다 — 공유 UI 요소(네비게이션 바) 기반이 전제
- 테마 선택 저장은 브라우저의 로컬 저장소를 활용하며, 서버 측 저장은 범위 밖이다
- 레퍼런스 사이트(me.revi1337.com)의 토글 아이콘은 Material Symbols의 light_mode(태양)와 dark_mode(달) SVG 아이콘을 사용한다
- 테마 전환 시 색상 팔레트만 변경되며, 페이지 구조나 레이아웃은 변경되지 않는다
- 토글 버튼의 접근성 레이블은 한국어로 제공한다 ("라이트 모드로 전환" / "다크 모드로 전환")
- 초기 페이지 로드 시 테마가 깜빡이는 현상(flash of unstyled content)이 발생하지 않아야 한다
