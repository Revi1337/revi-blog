# Quickstart: 게시글 이미지 라이트박스 모달 검증

이 문서는 구현 완료 후 Constitution Principle I(Feature-Level Verification)에 따라 실제로
기능을 구동해 검증하는 절차다.

## 사전 조건

- `photoswipe`가 설치되어 있다 (`package.json` dependencies에 포함).
- 본문에 이미지가 3장 이상 포함된 게시글이 최소 1개 필요하다(갤러리 탐색·경계 검증용). 없다면
  `content/articles/`의 기존 게시글 중 하나에 임시로 이미지를 2~3장 추가해 검증한 뒤 되돌린다.
- 본문에 이미지가 정확히 1장뿐인 게시글, 이미지가 하나도 없는 게시글도 각각 하나씩 있으면
  경계 케이스 검증에 유용하다(없다면 임시로 만들어 검증 후 되돌려도 된다).

## 1. 빌드 검증

```bash
npm run build
```

타입 에러/빌드 에러 없이 통과해야 한다.

## 2. 로컬 서버 기동

```bash
npm run dev
```

`http://localhost:3999/article/<slug>` 형태로 이미지가 여러 장 포함된 게시글 상세 페이지에
접속한다.

## 3. 브라우저 검증 (claude-in-chrome MCP 우선, 없으면 playwright-cli)

1. **본문 이미지 클릭(spec User Story 1 / FR-001, FR-003)**: 본문 이미지를 클릭했을 때
   뷰포트 전체를 덮지 않는 크기의 모달이 여백을 두고 열리는지 확인한다.
2. **배경 블러(FR-004)**: 모달이 열린 상태에서 뒷배경 콘텐츠(제목, 본문 텍스트 등)가 흐릿하게
   블러 처리되어 있는지, 완전히 가려지지는 않는지(SC-002) 확인한다.
3. **등장 모션(FR-005)**: 모달이 즉시 나타나지 않고 부드러운 확대 전환으로 나타나는지 확인한다.
4. **갤러리 탐색(spec User Story 2 / FR-011, FR-012, FR-013)**: 이미지가 3장 이상인 게시글에서
   모달을 열고, 다음/이전 조작으로 각 이미지로 이동되는지, 인디케이터("N / M")가 정확히
   갱신되는지, 첫 번째 이미지에서 "이전"과 마지막 이미지에서 "다음"이 비활성화/무동작인지
   확인한다.
5. **이미지 1장뿐인 게시글(Edge Case)**: 이전/다음 탐색 조작이 비활성화되거나 아무 동작도
   하지 않는지 확인한다.
6. **이미지 없는 게시글(Edge Case)**: 본문에 이미지가 없을 때 기존 화면과 동일하게 유지되고,
   콘솔 에러가 없는지 확인한다.
7. **썸네일 클릭(spec User Story 3 / FR-002, FR-014)**: 게시글 상단 썸네일을 클릭했을 때
   본문 이미지와 동일한 모달 UI(크기/블러/모션)가 열리고, 이전/다음 탐색 UI는 표시되지 않는지
   확인한다.
8. **확대/축소(spec User Story 4 / FR-006, FR-007)**: 모달 안 + 버튼을 눌러 이미지가 확대되고,
   - 버튼을 눌러 축소되는지 확인한다. 버튼을 반복해서 눌러 상한/하한에서 더 이상 변화가 없는지
   확인한다.
9. **닫기 및 배율 초기화(FR-008, FR-009)**: 닫기 버튼, 배경 클릭, ESC 키 각각으로 모달이
   닫히는지 확인하고, 확대한 상태로 닫은 뒤 같은 이미지를 다시 열었을 때 기본 배율로 돌아와
   있는지 확인한다.
10. **리사이즈/회전(Edge Case, SC-004)**: 모달이 열린 상태에서 브라우저 창 크기를 바꾸거나
    모바일 뷰포트로 전환해, 모달이 화면을 벗어나거나 잘리지 않는지 확인한다.
11. **다크/라이트 테마(Constitution Principle II)**: 사이트 테마 토글로 다크 → 라이트,
    라이트 → 다크 양쪽에서 모달 UI(배경 블러, 화살표, 인디케이터, +/- 버튼)가 각 테마 톤에
    맞게 표시되는지 확인한다.
12. **초기 로드 성능(research.md #8)**: 페이지 최초 로드 시 네트워크 요청 목록
    (`read_network_requests`)에 PhotoSwipe 관련 청크가 없다가, 이미지를 처음 클릭한 시점에만
    로드되는지 확인한다.

## 4. vercel-react-best-practices 재감사 (Constitution Principle III)

`components/article/image-lightbox-handler.tsx`, `components/article/article-header.tsx`
변경분을 다음 규칙 기준으로 재확인한다:

- `bundle-dynamic-imports`: PhotoSwipe JS/CSS가 클릭 시점(또는 핸들러 마운트 시)에만 동적
  `import()`로 로드되는가, 초기 번들에 포함되지 않는가.
- `client-event-listeners`: 본문 이미지 클릭 핸들러가 페이지당 document 레벨 리스너 1개만
  등록하는가 (`CodeCopyHandler`와 동일 패턴).

## 완료 기준

위 1~12단계에서 에러나 시각적 불일치, 요구사항 미충족이 발견되면 기능을 완료로 보지 않고
즉시 수정한다.
