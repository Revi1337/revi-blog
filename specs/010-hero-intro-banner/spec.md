# Feature Specification: 히어로 캐러셀 제거 및 자기소개 배너 교체

**Feature Branch**: `010-hero-intro-banner`

**Created**: 2026-07-29

**Status**: Draft

**Input**: User description: "현재 메인 홈 화면 최상단에는 히어로 캐러셀이 있다. 이 캐러셀은 최신 글 3개를 슬라이드로 보여주는데, 바로 아래 있는 Entry Stream 카드 그리드에도 똑같은 최신 글 3개가 다시 나타난다. 같은 정보가 화면 최상단과 그 바로 아래에 두 번 노출되어 정보로서의 가치가 없다. 이 캐러셀을 제거하고, 같은 위치를 정적인 자기소개 배너로 교체한다. 자기소개 배너는 블로그 운영자를 방문자에게 소개하는 순수 정보성 영역이다. 운영자가 이미 자신의 개인 포트폴리오 사이트에서 관리하고 있는 자기소개 문구(정체성을 드러내는 한 줄 헤드라인 + 몇 개의 핵심 가치/철학을 짧은 라벨과 설명으로 나열한 항목들)와 톤을 맞춘다. 다만 그 포트폴리오는 한/영 언어 전환 기능이 있어 문구 앞에 언어 태그가 붙어 있는데, 이 블로그는 단일 언어이므로 언어 태그는 노출하지 않는다. 배너는 두 영역으로 구성된다: 소개 문구를 담은 텍스트 영역과, 운영자를 상징하는 작은 정사각형 프로필 이미지(현재 파비콘과 동일한 이미지)다. 텍스트가 왼쪽, 이미지가 오른쪽에 온다. 이미지는 화면 폭이 넓어져도 일정한 크기를 유지하고, 텍스트 영역이 남는 공간을 채운다. 화면이 모바일 폭으로 좁아지면 이미지가 위에 작게, 텍스트가 그 아래로 세로로 쌓인다. 배너는 기존 캐러셀이 차지하던 카드형 경계(둥근 모서리를 가진 배경 박스) 안에 들어가지만, 캐러셀만큼 큰 높이를 차지하지 않는다. 내용물 양에 맞는 훨씬 더 작고 컴팩트한 높이여야 한다. 배너에는 어떠한 인터랙션도 없다 — 자동 재생, 이전/다음 이동, 슬라이드 인디케이터, 클릭 시 다른 페이지로 이동 같은 요소가 전혀 없는 완전히 정적인 정보 표시 영역이다. 배너는 다크/라이트 테마 양쪽 모두에서 동일한 구성과 정보를 보여주되 색상 팔레트만 테마에 맞게 달라진다. 기존 core/*.html 정적 디자인 레퍼런스 파일들은 이번 변경 범위에서 제외한다 — 이미 실제 구현과 어긋나 있는 상태이며, 이번 작업으로 추가로 동기화하지 않는다."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 홈 화면에서 자기소개 배너 확인 (Priority: P1)

블로그 방문자가 홈 화면에 진입하면, 기존 히어로 캐러셀이 있던 자리에서 블로그 운영자를 소개하는 정적 배너를 볼 수 있다. 이 배너는 최신 글과 무관한 독립적인 소개 정보(정체성을 드러내는 헤드라인, 핵심 가치/철학 항목들, 프로필 이미지)로 구성된다.

**Why this priority**: 기존 캐러셀은 Entry Stream 그리드와 동일한 최신 글 3개를 중복 노출해 정보 가치가 없었다. 이 배너 교체가 이번 기능의 핵심 목적이자 MVP다.

**Independent Test**: 홈 화면을 열어 최상단 배너 영역에 캐러셀 조작 요소(좌우 화살표, 인디케이터 점) 없이 소개 문구와 프로필 이미지만 표시되는지 확인하고, 바로 아래 Entry Stream 그리드의 글 목록과 배너 내용이 겹치지 않는지 확인할 수 있다.

**Acceptance Scenarios**:

1. **Given** 사용자가 홈 URL에 접속, **When** 페이지가 로드되면, **Then** 최상단 배너 영역에 헤드라인 한 줄, 핵심 가치/철학을 나열한 항목들, 프로필 이미지가 표시된다
2. **Given** 배너가 표시됨, **When** 배너를 살펴보면, **Then** 자동 재생되는 슬라이드, 이전/다음 버튼, 인디케이터 점 등 어떠한 캐러셀 조작 요소도 존재하지 않는다
3. **Given** 배너가 표시됨, **When** 배너 아래로 스크롤하면, **Then** Entry Stream 카드 그리드가 이어서 나타나며, 배너에 나온 정보와 그리드의 글 목록 사이에 중복되는 항목이 없다

---

### User Story 2 - 데스크탑 폭에서 배너의 텍스트/이미지 레이아웃 (Priority: P2)

방문자가 데스크탑 폭 화면에서 배너를 보면, 소개 문구가 왼쪽에, 운영자를 상징하는 정사각형 프로필 이미지가 오른쪽에 위치한 2단 구성을 볼 수 있다.

**Why this priority**: 레이아웃 구성은 배너의 핵심 시각 정체성이며, 반응형 동작과 직접 연결되므로 P1 다음으로 중요하다.

**Independent Test**: 데스크탑 폭(1200px 이상)에서 화면을 열어 텍스트와 이미지가 좌우로 배치되는지, 창 폭을 늘렸을 때 이미지 크기가 변하지 않고 텍스트 영역만 넓어지는지 확인할 수 있다.

**Acceptance Scenarios**:

1. **Given** 데스크탑 폭 화면에서 배너를 보면, **When** 페이지가 로드되면, **Then** 소개 문구는 왼쪽에, 프로필 이미지는 오른쪽에 표시된다
2. **Given** 배너가 표시된 상태에서, **When** 브라우저 창 폭을 넓히면, **Then** 프로필 이미지의 크기는 그대로 유지되고 텍스트 영역만 폭이 넓어진다

---

### User Story 3 - 모바일 폭에서 배너 (Priority: P2)

방문자가 모바일 폭(375px)에서 홈 화면을 열면, 프로필 이미지가 작게 위쪽에, 소개 문구가 그 아래에 세로로 쌓인 형태로 배너를 볼 수 있다.

**Why this priority**: spec 001에서 이미 정의된 모바일 반응형 기준(375px)을 배너도 동일하게 지켜야 하는 회귀 방지 대상이다.

**Independent Test**: 브라우저 창을 375px 폭으로 줄이고 배너가 세로로 쌓이는지, 이미지가 작아지는지 확인할 수 있다.

**Acceptance Scenarios**:

1. **Given** 모바일 폭(375px) 화면에서, **When** 배너를 보면, **Then** 프로필 이미지가 위쪽에 작게, 소개 문구가 그 아래에 세로로 배치된다

---

### Edge Cases

- 소개 문구(헤드라인, 철학 항목)의 텍스트 길이가 길어져 여러 줄로 감싸질 때, 우측 프로필 이미지의 크기나 위치가 깨지지 않아야 한다
- 다크/라이트 테마 전환 시 배너의 레이아웃과 텍스트는 동일하게 유지되고 색상 팔레트만 달라져야 한다
- 브라우저 폭을 데스크탑↔모바일 경계값 부근에서 리사이즈할 때 배너 레이아웃이 자연스럽게 전환되어야 한다

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 홈 화면 최상단(기존 히어로 캐러셀 위치)에 정적 자기소개 배너를 제공해야 한다
- **FR-002**: 배너는 운영자의 정체성을 드러내는 한 줄 헤드라인과, 핵심 가치/철학을 짧은 라벨과 설명으로 나열한 항목들을 포함해야 한다
- **FR-003**: 배너는 운영자를 상징하는 정사각형 프로필 이미지를 포함해야 한다 (현재 사이트 파비콘과 동일한 이미지)
- **FR-004**: 배너는 자동 재생, 이전/다음 이동, 인디케이터, 클릭을 통한 페이지 이동 등 어떠한 인터랙션 요소도 포함하지 않아야 한다
- **FR-005**: 데스크탑 폭에서 배너는 텍스트를 왼쪽에, 프로필 이미지를 오른쪽에 배치해야 한다
- **FR-006**: 프로필 이미지는 화면 폭이 넓어져도 고정된 크기를 유지해야 하며, 텍스트 영역이 남는 공간을 채워야 한다
- **FR-007**: 모바일 폭(375px)에서 배너는 프로필 이미지를 위에 작게, 텍스트를 그 아래에 세로로 배치해야 한다
- **FR-008**: 배너는 기존 캐러셀이 사용하던 카드형 경계(둥근 모서리, 배경 박스)를 유지하되, 내용에 맞는 컴팩트한 높이를 사용해야 하며 기존 캐러셀의 높이보다 뚜렷하게 작아야 한다
- **FR-009**: 배너는 다크/라이트 테마 모두에서 동일한 레이아웃과 내용을 표시해야 하며, 색상 팔레트만 테마에 따라 달라져야 한다
- **FR-010**: 배너의 소개 문구는 운영자가 개인 포트폴리오에서 이미 관리 중인 자기소개 문구와 톤을 일치시켜야 한다 (단, 포트폴리오에 존재하는 언어 태그 표기는 노출하지 않는다)
- **FR-011**: 시스템은 홈 화면에서 기존 히어로 캐러셀 및 그와 관련된 모든 인터랙션(자동 재생, 좌우 이동, 인디케이터)을 제거해야 한다
- **FR-012**: 구현은 각 사용자 스토리(Phase) 단위로 완료될 때마다, 애플리케이션을 재빌드한 뒤 실제 브라우저에서 해당 스토리의 동작을 확인해야 한다 — 개발 서버의 핫리로드 상태만으로 검증을 갈음할 수 없다

### Key Entities

- **자기소개 배너(Intro Banner)**: 홈 화면 최상단에 표시되는 정적 정보 영역 — 헤드라인, 철학 항목 목록, 프로필 이미지로 구성
- **철학 항목(Philosophy Item)**: 짧은 라벨과 설명 텍스트로 구성된 자기소개 세부 항목

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 홈 화면 최상단에서 최신 글과 중복되는 정보 없이 운영자 소개 정보만 노출된다 (배너 내용과 Entry Stream 카드 그리드 항목 간 중복 0건)
- **SC-002**: 배너에는 자동 재생, 좌우 이동, 인디케이터, 클릭 이동 등 조작 가능한 인터랙션 요소가 존재하지 않는다 (상호작용 요소 개수 0개)
- **SC-003**: 데스크탑 폭에서 창 너비를 임의로 늘려도 프로필 이미지 크기는 변하지 않고 텍스트 영역만 확장된다
- **SC-004**: 모바일 폭(375px)에서 배너가 세로로 쌓인 레이아웃으로 정상 표시된다
- **SC-005**: 다크/라이트 테마를 전환해도 배너의 레이아웃과 텍스트 내용은 동일하게 유지되고 색상만 변경된다
- **SC-006**: 배너의 세로 높이가 기존 히어로 캐러셀보다 뚜렷하게(체감상 절반 이하 수준으로) 작다

## Assumptions

- 배너에 사용할 헤드라인과 철학 항목 문구는 운영자가 개인 포트폴리오 사이트에서 이미 관리 중인 자기소개 콘텐츠를 기반으로 하며, 언어 태그만 제외하고 그대로 재사용한다
- 프로필 이미지는 현재 사이트 파비콘과 동일한 이미지를 재사용한다
- 반응형 기준점은 spec 001에서 정의한 값(모바일 375px)을 따른다
- 기존 `core/*.html` 정적 디자인 레퍼런스 파일은 이번 기능 범위에서 제외하며, 이번 변경으로 추가 동기화하지 않는다 (spec 001 당시의 스냅샷으로 유지)
- 배너는 홈 화면에만 적용되며, 다른 화면(아티클 상세, 북마크 등)에는 영향을 주지 않는다
